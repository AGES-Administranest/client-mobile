# client-mobile

App mobile do Administranest, em [React Native](https://reactnative.dev) (TypeScript).

## Requisitos

- Node 22 LTS (use `nvm use`, respeita o `.nvmrc`)
- Ambiente configurado conforme o guia [Set Up Your Environment](https://reactnative.dev/docs/set-up-your-environment)

## Getting Started

### 1. Instalar dependências

```sh
npm install
```

### 2. Iniciar o Metro

```sh
npm start
```

### 3. Rodar o app

Com o Metro rodando, em outro terminal:

```sh
# Android
npm run android

# iOS (primeiro instale os pods)
bundle install
bundle exec pod install
npm run ios
```
